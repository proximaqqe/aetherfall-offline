# Aetherfall Offline — Prototype 0.1

Godot 4.4.1, 3D Android offline MOBA prototype. No servers, ads or donations.

## Features
- 3D arena and isometric camera
- Touch joystick (left half of screen) and WASD for desktop
- Attack and skill buttons
- Simple enemy bot, HP, victory/defeat and restart
- GitHub Actions builds an Android debug APK

## Build APK
Go to Actions > Build Android APK > Run workflow. After success, download the artifact `Aetherfall-Android-APK` and extract `Aetherfall-debug.apk`.

This is a prototype, not a completed 5v5 MOBA. Debug APK is not suitable for store publishing.
